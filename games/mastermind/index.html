How to play

A secret four-colour code is hidden. Make a guess, then read the feedback dots:

  • ⚫ Black dot — right color, right position
  • ⚪ White dot — right color, wrong position
  • (no dot) — that color isn't in the code at all

Rules

  • Duplicates allowed in the code
  • 10 guesses to crack it
