Sudoku

Fill the grid so every row, column and box holds 1 to 9.

Click a cell, then type a number.

How to play

Click any empty cell and type a digit from 1 to 9. Every row, every column and every three-by-three box must contain each digit exactly once. Clashing numbers turn red so you can spot mistakes early.

Controls

  • Click a cell, then 1–9 to fill it
  • Backspace or 0 clears a cell
  • Arrow keys move the selection
  • Hint fills one correct cell for you
